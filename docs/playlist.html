Get this into your own Spotify or Apple library

Playlists live inside an account, so this last hop is yours to make — it takes about a minute:

  1. Download the import file above.
  2. Go to a free transfer tool (Soundiiz, TuneMyMusic, or Spotlistr).
  3. Choose import from file / text, upload the CSV (or paste the plain text list), and pick Spotify or Apple Music as the destination.
  4. Log in when prompted, name it, done — the whole cohort playlist lands in your library.

You can also click any Spotify link in the table above to open that song directly, and add it with the ⋯ menu.
